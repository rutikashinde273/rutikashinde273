## 🚀 Featured Projects

### 🔍 [Splunk SSH Brute-Force Detection](https://github.com/rutikashinde273/Splunk-SSH-BruteForce-Detection)
SOC monitoring project that analyzes Linux SSH authentication logs in **Splunk Enterprise** to detect brute-force attacks. It identifies failed and successful logins, suspicious source IPs, and targeted usernames, and visualizes them on a SOC dashboard.

### 🛡️ [DocuChain: Nexus Protocol V2.0](https://github.com/rutikashinde273/Docu-chain)
Zero-Trust document security system. A Chrome extension intercepts downloads and scans them for malware (VirusTotal), then verified files are stored in MinIO and their SHA-256 hashes are anchored on a **Hyperledger Fabric** blockchain to detect tampering.
